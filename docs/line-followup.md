# คู่มือ: ตามลูกค้าหลังเรียนออนไลน์ผ่าน LINE @jiacpr

> เป้าหมาย: นักเรียนที่เรียนจบ + สอบผ่านออนไลน์ → แอด LINE ทางการ @jiacpr →
> พนักงานทักตามต่อ เพื่อชวนมาสมัครคอร์สอบรม **ภาคปฏิบัติจริง** (CPR & AED กับหุ่น)

ออกแบบให้ **ไม่ต้องตั้งระบบอัตโนมัติ** — พนักงานทำงานใน LINE OA ที่ใช้อยู่แล้ว

---

## ภาพรวม flow

```
นักเรียนสอบผ่าน Post-test ≥ 80%
        │
        ▼
หน้า "ใบประกาศ" ขึ้นด่าน  ──►  "แอด LINE @jiacpr เพื่อรับใบประกาศ"
   (มีปุ่มเพิ่มเพื่อน + QR + ปุ่ม "ฉันแอดแล้ว")
        │
        ├──► นักเรียนแอด LINE @jiacpr → พิมพ์ "ชื่อ-เบอร์" ทักในแชท
        │         │
        │         ▼
        │    พนักงานเห็นใน LINE OA inbox → ทักตาม + ติด Tag
        │
        ▼
   กด "ฉันแอดแล้ว" → ปลดล็อก ดาวน์โหลดใบประกาศ PDF
```

> หมายเหตุ: ขั้นยืนยันเป็น **honor system** (กด "ฉันแอดแล้ว" ได้โดยระบบไม่ได้เช็คว่าแอดจริง)
> คนที่ตั้งใจอยากได้ใบเซอร์ส่วนใหญ่จะแอด — คนที่ไม่แอดคือ lead ที่สนใจน้อยอยู่แล้ว

---

## สิ่งที่ต้องตั้งค่าครั้งเดียวใน LINE OA (ไม่ต้องเขียนโค้ด)

ทำในแอป **LINE Official Account** (LINE OA Manager) ที่จัดการเพจ @jiacpr

### 1. ตั้ง "ข้อความต้อนรับ" (Greeting message)
เมนู: **การแชท → ข้อความทักทายเพื่อนใหม่**

ตัวอย่างข้อความ:
> ขอบคุณที่เรียนจบหลักสูตรปฐมพยาบาลออนไลน์ 🎉
> พิมพ์ **ชื่อ-เบอร์โทร** ของคุณไว้ในแชทนี้ได้เลยค่ะ
> ทีมงานจะติดต่อกลับ พร้อมสิทธิ์พิเศษคอร์สอบรม **ภาคปฏิบัติจริง (CPR & AED)** 🚑

> ข้อความนี้เด้งอัตโนมัติทันทีที่นักเรียนกดแอด — ทำให้ได้ชื่อ-เบอร์มาเอง

### 2. เตรียม Tag ไว้จัดกลุ่ม lead
เมนู: **การแชท → แท็ก** สร้างแท็กไว้ 3 อัน:
- `เรียนจบออนไลน์` — แปะทันทีที่นักเรียนทักเข้ามา
- `สนใจคลาส` — แปะเมื่อคุยแล้วเขาสนใจคอร์สปฏิบัติ
- `สมัครแล้ว` — แปะเมื่อปิดการขายได้

---

## พนักงานต้องทำอะไรบ้าง (งานประจำวัน)

1. เปิดแอป **LINE OA Manager** → แท็บ **แชท**
2. เห็นเพื่อนใหม่ที่พิมพ์ชื่อ-เบอร์เข้ามา → **ทักกลับ** แนะนำคอร์สปฏิบัติ
3. **ติด Tag** ตามสถานะ (`เรียนจบออนไลน์` → `สนใจคลาส` → `สมัครแล้ว`)
4. อยากดูเฉพาะคนที่ยังไม่ปิด → กรองด้วย Tag `สนใจคลาส`

เท่านี้พอ — ไม่มีระบบใหม่ให้เรียนรู้

---

## การติดตามผล (ดูว่าได้ผลแค่ไหน)

- **จำนวน lead** = จำนวนเพื่อนใหม่ของ LINE OA ในช่วงนั้น (ดูได้ใน LINE OA → สถิติ)
- **ฝั่งโฆษณา/เว็บ** ระบบยิง event เข้า Meta Pixel แล้ว:
  - `Lead` (source: `cert_line_gate`) — ตอนนักเรียนกดปุ่ม "เพิ่มเพื่อน LINE"
  - `CertLineGateConfirmed` — ตอนกด "ฉันแอดแล้ว"
  ใช้วัดได้ว่ามีคนผ่านด่าน LINE กี่คนต่อวัน

## อยากอัปเกรดทีหลัง (ยังไม่จำเป็นตอนนี้)

ถ้าธุรกิจโตขึ้นและอยากให้ **บังคับแอดจริง + เด้งแจ้งพนักงานอัตโนมัติ** ค่อยต่อ
LINE Messaging API (webhook) เพื่อ:
- ตรวจสอบว่านักเรียนแอดเพื่อนจริงก่อนปลดล็อกใบเซอร์
- ส่งการ์ด lead เข้ากลุ่มพนักงานอัตโนมัติพร้อมชื่อ-เบอร์จากระบบ
