❌ ห้ามใช้ "เรียนฟรี + ใบเซอร์" / "เรียนฟรี พร้อมใบเซอร์" — ไม่จริง:

- ถ้าเงื่อนไขในโค้ดเปลี่ยน ให้เช็คใหม่ก่อนใช้ CTA

## กฎ

1. **เนื้อหา**: ทุกประโยค (คำถาม, เหตุผลที่ผิด, วิธีที่ถูก, 1669) ต้องมาจากบทเรียนในเว็บ — ห้ามเติมเอง ถ้าข้อผิดไม่มีเหตุผลในเว็บ ให้เปลี่ยนคำถาม
2. **มือ**: ช่วง ✅ มือต้องนิ่ง ห้ามให้ AI ทำท่าหัตถการ (กด/พัน/รัด/CPR) เอง — ช่วง ❌ ขยับได้
3. **ห้ามมีตัวหนังสือ/ป้าย/ทะเบียนรถในภาพ** — ตัวหนังสือใส่ตอนตัดต่อ
4. **โทนสารคดีสมจริง** เลือดน้อย / ไม่โชว์อุบัติเหตุตอนเกิด (ใช้จอดำ + เสียงแทน)
5. **ความปลอดภัย**: ขี่มอไซต้องใส่หมวกกันน็อก ฯลฯ
6. ตอนโพสต์เปิด **"AI-generated content"**
7. ใช้ไฟล์ภาพต้นฉบับ ไม่ใช่ภาพแคปหน้าจอ
8. **เสียงในวิดีโอ**: ใส่เสียงธรรมชาติของฉาก (น้ำ, ตลาด, รถ) ได้ — ห้ามมีคนพูด/ตะโกนเป็นคำ (Veo พูดไทยเพี้ยน + ชนเสียงพากย์) และห้ามดนตรี

## ตัวละคร

- **คนช่วยประจำซีรีส์**: หญิงไทยวัย 30 เสื้อยืดเทาอ่อน ยีนส์ มัดผม (คนธรรมดา ไม่ใช่เจ้าหน้าที่) — ทำถูกเสมอ ใช้ภาพเธอจาก EP.15/16 เป็นรูปอ้างอิงทุกตอน
- **คนทำผิด (❌)**: ต้องหน้าตา/การแต่งตัวต่างจากคนช่วยประจำชัดเจน (เช่น ชายเสื้อโปโลฟ้า)
- **ผู้บาดเจ็บ/ผู้ป่วย**: เปลี่ยนตามตอน

### รูปแบบบรีฟส่ง GPT/ChatCut (ใช้ทุกตอน)

1. **ข้อแก้ที่อนุมัติแล้ว ไว้บนสุด** — ห้ามมี A/B / นับถอยหลังขนาด+ตำแหน่งเหมือน EP.15 / CTA "เรียนพื้นฐานฟรี 5 บท"
2. **บอกว่าต้องออกมาหน้าตาแบบไหน** ไม่ใช่แค่บอกว่าให้ขึ้นอะไร
3. **ระบุช่วงที่ต้องเทียบกับ EP.15 ทีละช่วง**: คำถาม / นับถอยหลัง / ❌ / ✅ / การ์ดเหลือง / การ์ดท้าย — ห้ามเขียนรวมๆ ว่า "ทำคล้ายตอนก่อน"
4. **คำถาม** = ประโยคธรรมดา ไม่มี A/B
5. **เสียงพากย์ vs ตัวหนังสือ**: พากย์เล่าได้ธรรมชาติ / ตัวหนังสือสรุปสั้น — ความหมายต้องตรงกัน ไม่ต้องอ่านตรงกันทุกคำ

เช็คภาพ: ถุงมือ / ผ้าอยู่บนแผลตรงๆ / ท่า "กด" ไม่ใช่ "ซับ" / ตำแหน่งมือ / ไม่มีตัวหนังสือ / ตัวละครต่อเนื่อง

## ตอนที่ทำแล้ว

### EP.16 — เลือดกำเดาไหล (บท 16)
- คำถาม: "เลือดกำเดาไหล เงยหน้า หรือ ก้มหน้า?"
- ❌ เงยหน้า → เลือดไหลลงคอ ไอ อาเจียน สำลัก
- ✅ นั่งเอนตัวไปข้างหน้า บีบปีกจมูก **10 นาที ห้ามปล่อยดู** (แก้จาก 2–3 นาทีตามแนวทางสากล) / ยังไม่หยุดบีบแน่นขึ้น
- 1669: เกิน 15 นาทีไม่หยุด / เลือดออกมากขึ้น / หายใจไม่ได้
- ฉาก: ห้องนั่งเล่น ผู้ชายเสื้อขาว + คนช่วยประจำ

### EP.15 — เลือดออก รีบรัด หรือ กดแผลก่อน? (บท 15)
- เปิด: ขี่มอไซ 1.5 วิ (ใส่หมวก) → จอดำ "โครม"
- คำถาม: "เลือดออก รีบรัด หรือ กดแผล?"
- ❌ ชายเสื้อโปโลฟ้าถอดเข็มขัดจะมารัด → รัดใช้เฉพาะเลือดออกมากจากแขนขาที่กดแล้วไม่หยุด
- ✅ ใส่ถุงมือ วางผ้าบนแผล กดตรงๆ / ยังไหลซ้อนผ้า กดแน่นขึ้น จนหยุด
- 1669: เลือดออกมาก / หยุดไม่ได้ / ช็อก / สงสัยเจ็บหัว คอ หลัง / ไม่แน่ใจ
- ฉาก: ซอย สกู๊ตเตอร์แดงดำล้ม ผู้ชายเสื้อดำกางเกงขาสั้นกรมท่า + คนช่วยประจำ
- (วิดีโอเต็ม 2 นาทีแนวนอนของบทนี้อยู่ที่ `../15-bleeding.md`)

- **เลือดกำเดา (บท 16 / EP.16)**: เว็บเขียน "บีบนาน 2-3 นาที" (`lessons.js` หัวข้อ "เลือดกำเดา") แต่แนวทางสากล (กาชาดอังกฤษ, NHS, Healthdirect) ให้บีบ ~10 นาทีโดยไม่ปล่อยดู → คลิป EP.16 แก้เป็น 10 นาทีแล้ว / **เว็บยังไม่แก้ — รอหมอเจี่ย/บอสยืนยัน** แล้วค่อยแก้เว็บให้ตรงกับคลิป
- **กฎเพิ่ม**: ทุกตอนให้เทียบเนื้อหากับทั้งเว็บ และแนวทางสากล (AHA/กาชาด 2024, ANZCOR/ILCOR) — ถ้าไม่ตรง แจ้งก่อน gen ภาพ

- หน้าแรกเว็บเขียน "คอร์สออนไลน์ฟรี" (`src/pages/Landing.jsx`) กว้างกว่าความจริง → เรื่องการตลาด ให้บอสตัดสินใจ
- โฆษณา Facebook Ad B "เรียนฟรี 1 ชม. + ใบเซอร์" ปัญหาเดียวกับ CTA เดิม
