## EP.21 — งูกัด ต้องรัดเหนือแผล ดูดพิษออกไหม? (บท 21 กัด/ต่อย)

| วินาที | ภาพ | พากย์ | บนจอ |
|---|---|---|---|
| 0–3 | คลิป 1 ชาวนาวัย 50 นั่งริมคันนา กุมน่อง มีรอยเขี้ยว 2 จุด | "โดนงูกัดที่ขา ต้องรีบรัดเหนือแผล แล้วดูดพิษออกไหม?" | ❓ งูกัด ต้องรัดเหนือแผล ดูดพิษออกไหม? |
| 3–6 | ค้างเฟรม + 3-2-1 | "ตอบในคอมเมนต์!" | ตอบในคอมเมนต์! |
| 6–11 | คลิป 2 ❌ ผู้ชายเสื้อลายพรางรัดเชือกเหนือแผล ก้มจะดูด | "ห้ามทั้งคู่! ห้ามรัดเหนือแผล ห้ามดูดพิษด้วยปาก และห้ามกรีดแผล" | ❌ ห้ามรัด / ห้ามดูดพิษ / ห้ามกรีด |
| 11–19 | คลิป 3a ✅ ผู้ป่วยนั่งนิ่ง ขาวางนิ่ง คนช่วยใส่ถุงมือ ถอดนาฬิกาให้ โทร 1669 | "ที่ถูกคือให้คนอื่นถอยออก ใส่ถุงมือ โทร 1669 ให้นั่งนิ่งๆ สงบ ห้ามขยับส่วนที่โดนกัด ถอดของรัดแน่นออก" | ✅ ถอยห่างงู → ถุงมือ → โทร 1669 → นั่งนิ่ง ห้ามขยับส่วนที่โดนกัด → ถอดเครื่องประดับ/ของรัด |
| 19–27 | คลิป 3b ซูมช้า | "ไม่รู้ว่างูอะไร ให้คิดว่ามีพิษไว้ก่อน ล้างแผลด้วยน้ำสะอาด และห้ามแตะงู แม้จะตายแล้วก็ยังกัดได้" | การ์ดเหลือง: ไม่รู้ชนิด = คิดว่ามีพิษ / ล้างแผลน้ำสะอาด (ฟอกสบู่ถ้ามี) / ห้ามแตะงู แม้ตายแล้ว |
| 27–30 | การ์ดท้าย | CTA | CTA |

| ในคลิป | อ้างอิงเว็บ (บท 21) |
|---|---|
| ห้ามดูด / กรีด / รัด / แตะงู | callout "งูกัด — ห้าม" |
| ขั้นตอน + ไม่รู้ชนิด = มีพิษ | "งูกัด" |

⚠️ ไม่โชว์ตัวงูกัด (ถ้ามี ให้เป็นงูเล็กไกลๆ เลื้อยหนี) / แผลแค่รอยเขี้ยว 2 จุด ไม่มีเลือดมาก

## EP.22 — ทำงานกลางแดด เพื่อนพูดจาสับสน ให้นั่งพักในร่มพอไหม? (บท 22 ร้อนจัด/ลมแดด)

| วินาที | ภาพ | พากย์ | บนจอ |
|---|---|---|---|
| 0–3 | คลิป 1 คนงานก่อสร้างวัย 40 กลางแดด หน้าแดง เซ ตาลอย | "ทำงานกลางแดดทั้งวัน เพื่อนเริ่มพูดจาสับสน เดินเซ ให้นั่งพักในร่มพอไหม?" | ❓ ทำงานกลางแดด เพื่อนสับสน เดินเซ นั่งพักในร่มพอไหม? |
| 3–6 | ค้างเฟรม + 3-2-1 | "ตอบในคอมเมนต์!" | ตอบในคอมเมนต์! |
| 6–11 | คลิป 2 ❌ เพื่อนเสื้อกั๊กส้มให้นั่งพิงเสา แล้วเดินกลับไปทำงาน | "ไม่พอ! สับสน เวียนหัว อาจเป็นลมแดด อันตรายถึงชีวิต ต้องลดอุณหภูมิให้เร็วที่สุดในนาทีแรก" | ❌ ลมแดด = ถึงชีวิต! ต้องลดความร้อนทันที |
| 11–19 | คลิป 3a ✅ ให้นอนในที่ร่ม คนช่วยใส่ถุงมือ วางผ้าเย็นที่คอ | "ที่ถูกคือใส่ถุงมือ โทร 1669 ให้นอนในที่เย็น วางผ้าเย็นที่คอ รักแร้ ขาหนีบทันที ถ้าไม่มีผ้า ให้พ่นละอองน้ำ" | ✅ ถุงมือ → 1669 → นอนที่เย็น → ผ้าเย็น คอ/รักแร้/ขาหนีบ (หรือพ่นละอองน้ำ) |
| 19–27 | คลิป 3b ซูมช้า | "อาการลมแดด สับสน เวียนหัว ปัสสาวะราด ชัก ถ้ากลืนได้ให้ดื่มเกลือแร่ ถ้าปลุกไม่ตื่น ไม่หายใจ ปั๊มหัวใจทันที" | การ์ดเหลือง: ลมแดด = สับสน · เวียนหัว · ปัสสาวะราด · ชัก / กลืนได้ → เกลือแร่ / ไม่หายใจ → ปั๊มหัวใจ |
| 27–30 | การ์ดท้าย | CTA | CTA |

| ในคลิป | อ้างอิงเว็บ (บท 22) |
|---|---|
| ลมแดดถึงชีวิต / อาการ | callout "ลมแดด" + quiz |
| ขั้นตอน + ลดอุณหภูมิในนาทีแรก / พ่นละอองน้ำ / เกลือแร่ / CPR | "ขั้นตอนลมแดด" |

⚠️ เสื้อคนงาน/เสื้อกั๊ก ห้ามมีโลโก้/ตัวหนังสือ / ไม่ให้ AI โชว์การถอดเสื้อผ้า

## EP.23 — ตากฝนบนดอย หนาวจนหยุดสั่น ง่วงมาก ให้นอนพักได้ไหม? (บท 23 เย็นจัด)

เลือกมุม "ภาวะตัวเย็น (Hypothermia)" — ใกล้ตัวคนไทยกว่าน้ำแข็งกัด และเลี่ยงเรื่อง "ห้ามละลายน้ำแข็ง" ที่เว็บกับสากลไม่ตรงกัน (ดู README)

| วินาที | ภาพ | พากย์ | บนจอ |
|---|---|---|---|
| 0–3 | คลิป 1 ชายวัย 30 นั่งหน้าเต็นท์บนดอยกลางคืน เสื้อเปียกโชก ปากซีดคล้ำ ง่วงซึม | "ตากฝนบนดอยทั้งคืน เพื่อนหนาวจนหยุดสั่น ง่วงมาก ให้นอนพักในเต็นท์ได้ไหม?" | ❓ หนาวจนหยุดสั่น ง่วงมาก ให้นอนพักได้ไหม? |
| 3–6 | ค้างเฟรม + 3-2-1 | "ตอบในคอมเมนต์!" | ตอบในคอมเมนต์! |
| 6–11 | คลิป 2 ❌ เพื่อนเสื้อแดงพาเข้าเต็นท์นอนทั้งชุดเปียก | "อันตราย! หยุดสั่นแปลว่าร่างกายปรับอุณหภูมิไม่ได้แล้ว ภาวะตัวเย็นถึงชีวิตได้ทันที" | ❌ หยุดสั่น = อันตรายมาก! |
| 11–19 | คลิป 3a ✅ คนช่วยห่มผ้าห่มหลายชั้นในที่อุ่น เว้นหน้าไว้ | "ที่ถูกคือย้ายเข้าที่อุ่น ถอดชุดเปียก เปลี่ยนชุดแห้ง ห่อตัวด้วยผ้าห่มหลายชั้น เว้นใบหน้า แล้วโทร 1669" | ✅ เข้าที่อุ่น → ถอดชุดเปียก → ชุดแห้ง → ห่อผ้าห่ม (เว้นหน้า) → โทร 1669 |
| 19–27 | คลิป 3b ซูมช้า | "ห้ามเอาของร้อนจัดหรือน้ำร้อนมาโดนตัว ถ้าปลุกไม่ตื่น ไม่หายใจ ปั๊มหัวใจทันที" | การ์ดเหลือง: ห้ามของร้อนจัด/น้ำร้อนโดนตัว / ปลุกไม่ตื่น ไม่หายใจ → ปั๊มหัวใจ / ส่ง รพ. เร็วที่สุด |
| 27–30 | การ์ดท้าย | CTA | CTA |

| ในคลิป | อ้างอิงเว็บ (บท 23) |
|---|---|
| หยุดสั่น = อันตรายมาก / ถึงชีวิตทันที | callout "ภาวะตัวเย็น" |
| อาการ: สับสน ง่วงซึม ผิวฟ้า | "อาการภาวะตัวเย็น" |
| ขั้นตอน 1–7 | "ขั้นตอน" |
| ห้ามของร้อนจัด | callout "ห้ามใช้ของร้อนจัด" |

⚠️ ไม่โชว์การถอดเสื้อผ้า — ภาพ ✅ ห่มผ้าแล้ว / ตัวละครผู้ใหญ่ชัดเจน
