## EP.20 — คนโดนไฟดูด รีบดึงตัวออกเลยไหม? (บท 20 แผลไหม้และไฟฟ้าช็อต)

เลือกมุม "ไฟฟ้าช็อต" — เลี่ยงเรื่องอุณหภูมิน้ำล้างแผลไหม้ที่เว็บกับสากลยังไม่ตรงกัน (ดู README เรื่องค้าง)

| วินาที | ภาพ | พากย์ | บนจอ |
|---|---|---|---|
| 0–3 | คลิป 1 ผู้ชายวัย 40 ล้มข้างพัดลมตั้งพื้นที่สายไฟขาด มือยังจับสาย | "คนโดนไฟดูด ล้มอยู่ มือยังจับสายไฟ รีบเข้าไปดึงตัวออกเลยไหม?" | ❓ คนโดนไฟดูด รีบเข้าไปดึงตัวออกเลยไหม? |
| 3–6 | ค้างเฟรม + 3-2-1 | "ตอบในคอมเมนต์!" | ตอบในคอมเมนต์! |
| 6–11 | คลิป 2 ❌ ผู้หญิงเสื้อเหลืองพุ่งเข้าไปจะจับแขน | "หยุด! จับตัวคนที่ยังติดกระแสไฟ เราก็โดนไฟดูดด้วย" | ❌ อย่าแตะ! ยังติดไฟ = เราโดนด้วย |
| 11–19 | คลิป 3a ✅ คนช่วยสับสะพานไฟใหญ่ลง | "ที่ถูกคือปิดสะพานไฟใหญ่ก่อนทุกครั้ง แล้วใส่ถุงมือ โทร 1669" | ✅ ปิดสะพานไฟใหญ่ก่อน → ถุงมือ → โทร 1669 |
| 19–27 | คลิป 3b ซูมช้า | "ไฟฟ้าช็อตไหม้จากข้างในออกมา แผลข้างนอกอาจดูนิดเดียว แต่ทำให้หัวใจเต้นผิดจังหวะได้ ถ้าปลุกไม่ตื่น ไม่หายใจ ปั๊มหัวใจทันที แล้วส่งโรงพยาบาลทุกครั้ง" | การ์ดเหลือง: ไหม้จากในออกนอก แผลนอกดูน้อย · หัวใจเต้นผิดจังหวะได้ / ปลุกไม่ตื่น ไม่หายใจ → ปั๊มหัวใจ / ส่งโรงพยาบาลทันที |
| 27–30 | การ์ดท้าย | CTA | CTA |

| ในคลิป | อ้างอิงเว็บ (บท 20) |
