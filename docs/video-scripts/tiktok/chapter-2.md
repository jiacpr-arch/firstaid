## EP.6 — เพื่อนหอบกำเริบ พ่นยาแทนเขาเลยไหม? (บท 6 หายใจไม่ออก/หอบหืด)

เทียบแนวทางสากล (Asthma first aid / กาชาด): ผู้ช่วยช่วยให้ผู้ป่วยใช้ยาพ่นของตัวเอง นั่งหลังตรง → ตรงกับเว็บ / จำนวนครั้งที่พ่น (4×4) เว็บไม่มี → ไม่ใส่

| วินาที | ภาพ | พากย์ | บนจอ |
|---|---|---|---|
| 0–3 | คลิป 1 หญิงวัยทำงาน ~30 นั่งหอบ มือกุมอก ในฟู้ดคอร์ทออฟฟิศ | "เพื่อนหอบกำเริบ หายใจมีเสียงวี้ด เราควรพ่นยาแทนเขาเลยไหม?" | ❓ เพื่อนหอบกำเริบ ควรพ่นยาแทนเขาเลยไหม? |
| 3–6 | ค้างเฟรม + 3-2-1 | "ตอบในคอมเมนต์!" | ตอบในคอมเมนต์! |
| 6–11 | คลิป 2 ❌ ผู้ชายเสื้อเหลืองคว้ายาจะพ่นใส่ปากเธอ | "อย่าพ่นแทน! ต้องตรวจยากับเจ้าตัวให้ถูกก่อนทุกครั้ง และอย่าพ่นรัวๆ" | ❌ อย่าพ่นแทน / อย่าพ่นรัว |
| 11–19 | คลิป 3a ✅ คนช่วยยื่นยาให้ เธอนั่งหลังตรงพ่นเอง | "ที่ถูกคือถามหายาของเขา ตรวจให้ถูก ช่วยหยิบ ประกอบยา แล้วให้นั่งหลังตรงพ่นเอง" | ✅ ถามหายา → ตรวจให้ถูก → ช่วยหยิบ/ประกอบ → นั่งหลังตรง พ่นเอง |
| 19–27 | คลิป 3b คนช่วยนั่งข้างๆ สังเกตอาการ | "ถ้าไม่มียา พ่นแล้วไม่ดีขึ้น หรือแย่ลงจนพูดไม่ได้ โทร 1669" | การ์ดเหลือง: โทร 1669 เมื่อ ไม่มียา / พ่นแล้วไม่ดีขึ้น / แย่ลง พูดไม่ได้ ปลุกไม่ตื่น |
| 27–30 | การ์ดท้าย | CTA | CTA |

| ในคลิป | อ้างอิงเว็บ (บท 6) |
|---|---|
| หายใจมีเสียงวี้ด | "อาการที่สังเกตได้" |
| ไม่พ่นแทน / ไม่พ่นรัว / ตรวจยา + ช่วยหยิบ/ประกอบ | quiz (ข้อ c, d ผิด / b ถูก) + explanation |
| ถามหายา / นั่งหลังตรง | "การพ่นยา" ย่อหน้าแรก + ข้อ 4 |
| 1669 เมื่อ... | "โทร 1669 เมื่อ" |

⚠️ ยาพ่น: ห้ามมีตัวหนังสือ/ฉลาก / ✅ ไม่ต้องโชว์ขั้นตอนพ่นละเอียด (กฎข้อ 2)

## EP.7 — คนสำลักแต่ยังไอได้ ต้องรีบกระทุ้งท้องไหม? (บท 7 สำลัก)

เลือกมุม "อาการเบา" เพื่อไม่ต้องให้ AI ทำท่า Heimlich (กฎข้อ 2) และเลี่ยงเรื่องตบหลังที่เว็บกับสากลยังไม่ตรงกัน (ดู README เรื่องค้าง)

| วินาที | ภาพ | พากย์ | บนจอ |
|---|---|---|---|
| 0–3 | คลิป 1 ผู้ชายวัยทำงานไอหนักที่โต๊ะร้านข้าว มือปิดปาก | "คนสำลักแต่ยังไอเสียงดังได้ ต้องรีบกระทุ้งท้องเลยไหม?" | ❓ สำลักแต่ยังไอได้ ต้องรีบกระทุ้งท้องไหม? |
| 3–6 | ค้างเฟรม + 3-2-1 | "ตอบในคอมเมนต์!" | ตอบในคอมเมนต์! |
| 6–11 | คลิป 2 ❌ ผู้ชายเสื้อส้มพุ่งเข้าไปจะกอดจากด้านหลัง | "ยังไม่ต้อง! ถ้ายังพูดได้ ไอมีเสียงดัง คืออาการเบา" | ❌ ไอได้ = อาการเบา ยังไม่ต้องกระทุ้ง |
| 11–19 | คลิป 3a ✅ คนช่วยยืนข้างๆ เฝ้าดู ให้เขาไอต่อ | "ที่ถูกคือให้เขาไอต่อ แล้วสังเกตอาการ ถ้ากังวลให้โทร 1669" | ✅ ให้ไอต่อ → สังเกตอาการ → กังวล โทร 1669 |
| 19–27 | คลิป 3b ซูมช้า | "แต่ถ้าไอไม่มีเสียง พูดไม่ได้ เอามือกุมคอ คืออาการรุนแรง ต้องกระทุ้งท้องทันที และโทร 1669 ทุกครั้ง" | การ์ดเหลือง: อาการรุนแรง = ไอไม่มีเสียง / พูดไม่ได้ / มือกุมคอ → กระทุ้งท้องทันที + โทร 1669 ทุกครั้ง |
| 27–30 | การ์ดท้าย | CTA | CTA |

| ในคลิป | อ้างอิงเว็บ (บท 7) |
|---|---|
| อาการเบา: พูดได้ ไอเสียงดัง → สังเกต / กังวลโทร 1669 | "ประเมินการสำลัก" |
| อาการรุนแรง → เข้าช่วยทันที | "ประเมินการสำลัก" |
| โทร 1669 ทุกครั้งหลังกระทุ้ง | "โทร 1669 ทุกครั้ง" |

## EP.8 — แพ้กุ้ง หน้าบวม หายใจลำบาก รอดูอาการก่อนได้ไหม? (บท 8 แพ้รุนแรง)

| วินาที | ภาพ | พากย์ | บนจอ |
|---|---|---|---|
| 0–3 | คลิป 1 ผู้ชายวัย 30 ในร้านซีฟู้ด ปากบวม หน้าบวม หายใจลำบาก | "เพื่อนแพ้กุ้ง ปากบวม หายใจลำบาก รอดูอาการก่อนได้ไหม?" | ❓ แพ้กุ้ง ปากบวม หายใจลำบาก รอดูอาการก่อนได้ไหม? |
| 3–6 | ค้างเฟรม + 3-2-1 | "ตอบในคอมเมนต์!" | ตอบในคอมเมนต์! |
| 6–11 | คลิป 2 ❌ เพื่อนเสื้อม่วงโบกมือ "เดี๋ยวก็หาย" นั่งกินต่อ | "รอไม่ได้! แพ้จากเบาไปรุนแรงใช้เวลาแค่ 2–3 นาที" | ❌ รอไม่ได้! แค่ 2–3 นาทีก็รุนแรงได้ |
| 11–19 | คลิป 3a ✅ ผู้ป่วยถือปากกาฉีดยาของตัวเองไว้ที่ต้นขา คนช่วยอยู่ข้างๆ | "ที่ถูกคือใช้ปากกาฉีดยาของเขาทันที ฉีดที่ต้นขา ผ่านกางเกงได้เลย" | ✅ ใช้ปากกาฉีดยา (EpiPen) ทันที → ต้นขา ผ่านกางเกงได้ |
| 19–27 | คลิป 3b คนช่วยโทรศัพท์ | "แล้วโทร 1669 จดเวลาที่ฉีด ถ้าฉีดแล้วปลุกไม่ตื่น ปั๊มหัวใจทันที" | การ์ดเหลือง: โทร 1669 + จดเวลาที่ฉีด / ฉีดแล้วปลุกไม่ตื่น → ปั๊มหัวใจทันที |
| 27–30 | การ์ดท้าย | CTA | CTA |

| ในคลิป | อ้างอิงเว็บ (บท 8) |
|---|---|
| 2–3 นาทีจากเบาไปรุนแรง | callout "นาทีชีวิต" |
| อาการรุนแรง: หายใจไม่ออก หน้าบวม ปากบวม | "อาการแพ้" + quiz |
| ฉีด EpiPen ที่ต้นขา ผ่านเสื้อผ้าได้ / จดเวลา | "การใช้ปากกาฉีดยา" |
| 1669 / ปลุกไม่ตื่น → ปั๊มหัวใจ | quiz explanation + callout |
